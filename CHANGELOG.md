# Changelog

## 1.2.0 (2026-09-24)

- **Reminder only moves when unlocked.** The reminder could be dragged (and blocked clicks)
  while locked. It now ignores the mouse until you unlock it.
- **Type exact values.** Every slider in the options has a box beside it. Type a number and
  press Enter; the arrows and slider still work.

## 1.1.0 (2026-09-21)

- **No assignment by default.** "My number" and "My side" now have a None option, and None is
  the default. Players without a number get no reminder and no green box; turn on "Show all
  numbers" to see every number and help back up missed kicks.
- **Broadcasts clear old assignments.** Anyone not on the broadcast list is set back to None, so
  nobody keeps a stale number from a previous night.
- **Movable reminder.** New "Unlock reminder" option (or `/tfia unlock`) shows the reminder so you
  can see it and drag it into place. Right-click it to lock. The X/Y offsets update automatically.
- **Assignments window open to everyone.** Any raid member can open it to see the current kick
  assignments. Editing and broadcasting remain limited to the raid leader and assistants.

## 1.0.0 (2026-09-18)

- First release: Broodling nameplate numbers, interrupt reminder, raid leader assignments,
  group version check.
