# Twin Fangs Interrupt Assignments

Numbers the hostile nameplates on **The Twin Fangs** so a raid can assign interrupts
per add, instead of everyone kicking the same target.

## What it does

- **Numbered nameplates** — each Broodling gets a numbered box above its nameplate.
  By default you only see the box for *your* number; `Show all` draws every one.
- **Kick reminder** — a countdown ("Kick #n Left") before your pair's first cast,
  with an optional LibSharedMedia sound.
- **Assignments** — the raid leader fills in a Left/Right list and broadcasts it;
  every copy of the addon picks it up over addon comms.
- **Version check** — asks the group who is running what, and lists the answers.

Mythic only for the numbering: Heroic has no Broodlings and a different Ithraz
cast cycle.

## Install

Grab the latest zip from the releases/files page and unzip it into
`World of Warcraft\_retail_\Interface\AddOns\`, so you end up with
`AddOns\TwinFangsInterruptAssignments\TwinFangsInterruptAssignments.toc`.

## Options

`/tfia` opens the options panel.
